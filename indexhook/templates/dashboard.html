Ring setup (Pebble app on Android)

  1. Open the Pebble app and go to the Index tab, then open its settings.
  2. Find the Webhook section. Set Webhook URL to {{ hook_url }}
  3. Under Headers add one header. Name: X-Hook-Token. Value: your token{% if new_token %} ({{ new_token }}){% endif %}.
    Authorization with the value Bearer <token> works too. Behind YunoHost use X-Hook-Token, because its single sign-on layer can change the Authorization header.
  4. Set Send to both (recording and transcription). The recording is what gets transcribed here. The ring's own transcript is kept as a fallback.
  5. Set Trigger to the button combination you want, or to all triggers. The Index agent still runs for each recording, so choosing a dedicated combination avoids double handling.
  6. Make a short recording. It should appear under Recordings within a few seconds.

The app allows a single webhook. To check the server without the ring, use the Test page.
